# Raspberry Pi Pico 2 SD Card Read/Write Test

## 1. 概要
本プロジェクトは、Raspberry Pi Pico 2において、SPIインターフェースを介したMicroSDカードの基本的な読み書き（Read/Write）動作を検証するためのテストプログラムである。
将来的なBASICプログラム（`CAS:` や `0:` ドライブ）のセーブ/ロード機能実装に向けた、ストレージモジュールの技術検証（PoC）として位置づける。

## 2. ハードウェア仕様
* **ターゲットボード**: Raspberry Pi Pico 2
* **モジュール**: MicroSDカードスロット
* **インターフェース**: SPIモード（※物理配線はSDIO 4bit通信にも対応）

### 2.1 ピンアサイン (SPIモード動作時)
| 信号名 (SD側) | 役割 (SPI) | Pico 2 GPIOピン | 備考 |
| :--- | :--- | :--- | :--- |
| SD_SCK | **SCK** | **GPIO 19** | SPI0 SCK |
| SD_CMD | **MOSI** | **GPIO 20** | SDIOのCMDピンをSPIのMOSIとして使用 |
| SD_D0  | **MISO** | **GPIO 21** | SDIOのD0ピンをSPIのMISOとして使用 |
| SD_D3  | **CS** | **GPIO 24** | SDIOのD3ピンをSPIのCSとして使用 |

*(注: SD_D1(GPIO 22), SD_D2(GPIO 23) はSPIモードでは未使用)*

## 3. ソフトウェア仕様
* **開発環境**: Raspberry Pi Pico C/C++ SDK
* **ファイルシステム**: FAT32 (PC側で事前フォーマット済みであることを前提とする)
* **使用ライブラリ**: FatFs (汎用FATファイルシステムモジュール) およびハードウェアラッパー

## 4. 機能要件 (Acceptance Criteria)
1. **初期化**: 指定されたGPIOピン（19, 20, 21, 24）を使用してSPI0バスを適切に初期化できること。
2. **マウント**: FAT32でフォーマットされたSDカードを正常にマウントできること。
3. **ファイル書き込み**: 新規テキストファイル（例: `test_rw.txt`）を作成し、任意のテスト文字列を書き込んでクローズできること。
4. **ファイル読み込み**: 書き込んだテキストファイルを読み込みモードでオープンし、内容をバッファに取得できること。
5. **シリアル出力**: 読み込んだ文字列データ、および各処理のステータス（成功・エラーコード）をUSBシリアル（標準出力）経由でPCのコンソールに表示できること。
6. **エラーハンドリング**: SDカード未挿入時やマウント失敗時に、処理を停止し適切なエラーメッセージを出力すること。
